# ConceptSynthesis — установщики и обновления

Официальные сборки ConceptSynthesis для Windows 10 и новее, x64. В этом репозитории публикуются установщики и файлы проверки обновлений. Исходный код приложения хранится отдельно.

## Установка

Откройте [последний релиз](https://github.com/Tankolom-X/ConceptSynthesis-releases/releases/latest), скачайте `ConceptSynthesis-Setup-<версия>.exe` и запустите его. Установка выполняется для текущего пользователя без прав администратора.

Для первой установки релизной v1.5.0 используйте установщик вручную. Последующие версии можно проверить кнопкой «О программе» в правом верхнем углу окна исследователя → «Проверить обновления».

Настройки и журналы установленной программы находятся в `%LOCALAPPDATA%/ConceptSynthesis` и сохраняются при обновлении. Если приложение уже использовалось в переносном виде, сохраните прежний `Config.ini`; при первом запуске новый пользовательский конфиг может быть создан копированием файла рядом с EXE.

## Файлы релиза

- `ConceptSynthesis-Setup-<версия>.exe` — установщик.
- `ConceptSynthesis-Setup-<версия>.exe.issig` — отдельная подпись ECDSA P-256/SHA-256, которую программа проверяет перед обновлением.
- `release-manifest.json` — версия, номер сборки, размеры файлов и SHA-256.

Подпись `.issig` предназначена для встроенного обновления и не является Windows Authenticode.
